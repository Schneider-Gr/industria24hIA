# _especulativo

Documentos que se apresentam como extração do Bubble mas contêm evidências
de inferência/alucinação (nomes de tipos e campos que contradizem a
extração confirmada em /bubble-export/data-types/extracao-2026-07.md).

NÃO usar como fonte para /docs até validação manual no editor Bubble.

Ver alerta detalhado na conversa do projeto sobre schema_banco-bubble.md:
nomes como `Pedido`, `Cotacao`, `Empresa`, `Produto`, `ItemPedido` não
batem com os nomes reais confirmados (`Loja_ecommerce`, `Produto_ecommerce`,
`LinhaItem`), e até os campos do tipo `acessos` (o único supostamente
"confirmado" nos dois documentos) divergem entre as duas fontes.
