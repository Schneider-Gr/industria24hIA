Modelo de Dados Industria24

87 tabelas no schema public, agrupadas por domínio. Chaves estrangeiras vêm dos Relationships gerados; as views (lojas_vitrine, produtos_vendaveis, pedidos_cliente, logistica_*) foram omitidas porque só reespelham as tabelas-base. Referências a auth.users (owner_id, cliente_id, afiliado_id, user_id) não têm FK declarada no tipo gerado e aparecem como USUARIO.

Núcleo comercial

Loja vende produto; pedido é por loja e se abre em linha_itens, onde mora o split (vendedor, Industria24, afiliado). repasses registra cada transferência.
